# Support

Gru is maintained independently. Support is provided through different channels depending on how you use the project.

## Open Source Support

Users of the open source version (MPL 2.0) receive community-level support:

- Bug reports and feature requests can be submitted through GitHub Issues.
- Community discussions and contributions are welcomed.
- Response times are not guaranteed, as issues are reviewed as time allows.

We appreciate clear and well-documented reports, as they help us address problems more effectively.

## Commercial Support

Holders of commercial licenses receive the same core support channels as open source users, along with access to updates during their active subscription period.

Commercial licenses do not include priority support, dedicated assistance, guaranteed response times, or custom development. Both the Indie and Business tiers provide the same level of support access.

## What We Provide

We focus on maintaining and improving Gru. This includes:

- Reviewing and addressing bug reports
- Considering feature suggestions that align with the project’s direction
- Providing updates and improvements during active commercial subscriptions

## What We Do Not Provide

Commercial licenses are for usage rights only. We do not offer:

- Priority or guaranteed response times
- Custom development or consulting
- On-demand feature implementation
- Special treatment based on license tier

## Reporting Issues

- General bugs and questions: use the GitHub issue tracker.
- Security vulnerabilities: report privately using the method in [Security.md](Security.md).

Clear reproduction steps and relevant details help us resolve issues more efficiently.

Thank you for using Gru.
