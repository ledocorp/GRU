# Gru Governance

**Product:** Gru (GRU)  
**Publisher:** LedoCorp  
**Primary maintainer:** Shawn Londono  

Gru is maintained under an independent, maintainer-led model. **Pull requests are not accepted** on the official public repository (see [Contributing.md](Contributing.md)).

## Core Principles

- **Maintainer Authority**  
  Shawn Londono (LedoCorp) has final decision-making authority over the official repository, releases, and project direction.

- **Forks welcome**  
  Anyone may fork under MPL 2.0 and build independently.

- **Selective adoption**  
  Useful external work may be referenced or adapted by the maintainer with attribution; that is not a PR merge program.

- **Independence**  
  The project is developed and maintained independently. Commercial licensing, if any, is deferred and separate from this MPL cut.

- **Transparency**  
  Major public decisions may be noted in release notes or docs when relevant.
